# Catatan Versi Demo/Portofolio

Repo ini adalah versi demo dari sistem CATALYST QC yang dipakai di pabrik. Perubahan dari versi asli:

- Semua koneksi ke backend (Google Apps Script) diputus dan diganti mock/dummy data lokal — tidak ada data yang benar-benar tersimpan/terkirim ke server manapun.
- Semua password/gate akses (SPV, area binding, dsb) dinonaktifkan — bebas dicoba tanpa password.
- Semua nama QC asli diganti 3 nama contoh: Haura, Fitri, Nafisah.
- Fitur terkait Google Sheets tracker/report (generate WA SPV, sheet management) disembunyikan dari UI karena bergantung pada backend spreadsheet asli.

Silakan eksplor bebas — semua tombol submit/take/return akan selalu "berhasil" dengan data dummy.
